Guide CMS – Croire & Penser

Guide de gestion du site

Apprenez à gérer votre site Croire & Penser en toute autonomie.
Aucune compétence technique requise.

💡 Cliquez sur le bouton bleu en bas à droite pour poser vos questions à l'assistant IA

Se connecter au CMS

Le CMS est votre espace d'administration. C'est ici que vous gérez tout le contenu du site.

1

Ouvrez votre navigateur

Allez sur votresite.com/cms

2

Entrez vos identifiants

Email : admin@croireetpenser.ca
Mot de passe : admin123

3

Cliquez "Se connecter"

Vous arrivez sur le tableau de bord.

Changez votre mot de passe après la première connexion

Créer un contenu

Articles, vidéos et podcasts — tout se crée depuis le même formulaire.

1

Menu → Contenus → + Nouveau contenu

Le formulaire de création s'ouvre.

2

Remplissez les champs

Titre, type (article/vidéo/podcast), catégorie, texte du contenu.

3

Ajoutez les médias

Vidéo : collez l'URL YouTube
Podcast : collez l'URL du fichier audio
Bannière : collez l'URL d'une image

4

Cochez "Publier immédiatement"

Sans cette case, le contenu reste en brouillon (invisible sur le site).

5

Cliquez "Créer"

Le contenu apparaît sur le site dans sa catégorie.

Où apparaît le contenu ?

EndroitCe qui s'affiche
Page d'accueilLes 6 derniers contenus publiés dans "Contenu récent"
Page Contenus → ArticlesTous les contenus de type "Article"
Page Contenus → VidéosTous les contenus de type "Vidéo" avec player YouTube
Page Contenus → PodcastsTous les contenus de type "Podcast" avec lecteur audio
Les visiteurs peuvent poser des questions directement sur chaque contenu

Ajouter une vidéo YouTube

1

Copiez l'URL YouTube

Exemple : https://www.youtube.com/watch?v=dQw4w9WgXcQ

2

CMS → Nouveau contenu → Type : Vidéo

Collez l'URL dans le champ "Lien vidéo".

3

Ajoutez une bannière (recommandé)

L'image servira de miniature cliquable. Au clic, la vidéo se lance.

Sans bannière, le player YouTube s'affiche directement

Gérer les témoignages

Les visiteurs soumettent des témoignages (texte, vidéo ou audio). Vous les modérez avant publication.

1

Menu → Témoignages

Vous voyez tous les témoignages avec leur statut.

2

Filtrez par statut

En attente = nouveaux, pas encore visibles
Approuvés = visibles sur le site

3

Actions disponibles

✅ Approuver → visible sur le site
⏳ Retirer → masqué du site
🗑 Supprimer → supprimé définitivement

Modifier les textes des pages

1

Menu → Pages

Sélectionnez la page à modifier (Accueil, À propos, Contact…).

2

Cliquez "Modifier"

La page s'ouvre dans un nouvel onglet en mode édition.

3

Cliquez sur un texte → modifiez-le

Les textes éditables sont entourés d'un cadre bleu.

4

Sauvegarde automatique

Chaque modification est sauvegardée instantanément.

Questions fréquentes

Le contenu ne s'affiche pas ?

→ Vérifiez que "Publier immédiatement" est coché dans le CMS.

La vidéo ne se lance pas ?

→ L'URL doit être au format : https://www.youtube.com/watch?v=XXXXX

Comment ajouter une image ?

→ Hébergez l'image en ligne (Imgur, Google Photos) et copiez le lien direct.

Le témoignage approuvé n'apparaît pas ?

→ Rafraîchissez la page avec Ctrl + F5.

Besoin d'aide ?

→ Utilisez l'assistant IA (bouton bleu en bas à droite) ou contactez support@croireetpenser.com
