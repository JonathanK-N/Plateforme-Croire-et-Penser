Page Contenus — Créer un contenu

La page Contenus affiche trois types de ressources : Articles, Vidéos et Podcasts. Voici comment créer chaque type.

Étapes pour créer n'importe quel contenu

1

CMS → Menu → Contenus → + Nouveau contenu

Le formulaire de création s'ouvre.

2

Remplissez les champs obligatoires

Titre : titre principal visible sur le site
Type : Article / Vidéo / Podcast (détermine où il apparaît)
Catégorie : une des 11 catégories thématiques
Résumé : texte court affiché sur la carte (max 200 caractères)

3

Rédigez le contenu principal

Utilisez l'éditeur de texte pour écrire l'article ou la description. Accepte le HTML pour la mise en forme.

4

Ajoutez les médias (selon le type)

Article → Collez l'URL d'une image de bannière
Vidéo → Collez l'URL YouTube dans "Lien vidéo"
Podcast → Collez l'URL du fichier audio

5

Ajoutez des tags (optionnel)

Tags séparés par des virgules. Exemple : apologétique, foi, raison

6

Cochez "Publier immédiatement"

⚠️ Sans cette case cochée, le contenu reste en brouillon et n'est PAS visible sur le site.

7

Cliquez "Créer"

Le contenu est immédiatement visible sur le site dans sa section et dans les 6 derniers contenus de l'accueil.

Le contenu apparaît aussi automatiquement sur la page d'accueil
L'URL de la bannière doit être un lien direct vers l'image (finissant par .jpg, .png, .webp)

1

Ouvrez le contenu en modification

Supprimer un contenu définitivement

1

CMS → Contenus → Cliquez l'icône poubelle

2

Confirmez la suppression

⚠️ Cette action est irréversible. Le contenu et ses commentaires sont supprimés définitivement.

Préférez "Dépublier" à "Supprimer" si vous avez un doute — vous pourrez toujours republier

Ajouter une Vidéo YouTube ou un Podcast

Vidéo YouTube — Étapes détaillées

1

Allez sur YouTube et copiez l'URL de la vidéo

Format attendu : https://www.youtube.com/watch?v=IDENTIFIANT
Exemple : https://www.youtube.com/watch?v=dQw4w9WgXcQ

2

CMS → Nouveau contenu → Sélectionnez Type : Vidéo

3

Collez l'URL dans le champ "Lien vidéo"

Le système convertit automatiquement l'URL en lecteur intégré.

4

Ajoutez une image de miniature (recommandé)

Collez l'URL d'une image JPG/PNG dans "Image de bannière". Elle s'affiche avant que la vidéo se lance.

Les URLs courtes YouTube (youtu.be/...) fonctionnent aussi

Podcast Audio — Étapes

1

Hébergez votre fichier audio en ligne

Options recommandées : SoundCloud (gratuit), Anchor/Spotify, ou tout lien MP3 public.

2

Copiez l'URL directe du fichier ou du flux

Doit se terminer par .mp3 ou être un lien de streaming valide.

3

CMS → Nouveau contenu → Type : Podcast → URL audio

Collez l'URL dans le champ "URL audio".

4

Publiez

Le lecteur audio apparaît sur la page Contenus → Podcasts. Les visiteurs peuvent écouter directement depuis leur navigateur.

Questions Fréquentes — FAQ Complète

Problèmes de publication

❓ Mon contenu ne s'affiche pas sur le site

→ Vérifiez que "Publier immédiatement" est bien coché dans le CMS. Si coché, rafraîchissez la page avec Ctrl+F5.

❓ Le contenu s'affiche dans le CMS mais pas sur le site

→ Vérifiez le champ "is_published". Si décoché, le contenu est en brouillon. Modifiez-le et cochez la case.

❓ L'image de bannière ne s'affiche pas

→ L'URL doit pointer directement vers le fichier image (finir par .jpg, .png ou .webp). Si vous utilisez Google Photos, générez un lien direct (pas un lien de partage).

Problèmes avec les vidéos

❓ La vidéo YouTube ne se lance pas

→ L'URL doit être au format : https://www.youtube.com/watch?v=XXXXXXXX
→ Les URLs privées ou non répertoriées peuvent être bloquées. Vérifiez les paramètres de confidentialité YouTube.

❓ Le podcast ne se lit pas

→ Vérifiez que le lien MP3 est bien un lien direct vers le fichier (pas une page de téléchargement). Testez-le en le collant dans votre navigateur.

Problèmes de modération

❓ Un témoignage approuvé n'apparaît pas

→ Rafraîchissez la page avec Ctrl+F5. Si toujours absent, vérifiez que is_approved = true dans le CMS.

❓ Une question Q&A n'apparaît pas après approbation

→ Vérifiez qu'une réponse a bien été rédigée avant approbation. Une question sans réponse reste masquée.

Problèmes de connexion

❓ Je n'arrive pas à me connecter au CMS

→ Vérifiez l'URL : croireetpenser.com/cms
→ Identifiants : admin@croireetpenser.ca / admin123
→ Videz le cache du navigateur (Ctrl+Shift+Delete) et réessayez.

❓ J'ai perdu mon mot de passe

→ Contactez le développeur : jonathan.kakesa@cognito-inc.ca

Autres questions

❓ Comment ajouter une nouvelle catégorie thématique ?

→ Les 11 catégories sont configurées dans la base de données. Pour en ajouter une, contactez le développeur.

❓ Comment changer les informations de donation (compte PayPal, etc.) ?

→ Ces informations sont dans les variables d'environnement du serveur. Contactez le développeur technique.
