# 📖 Guide d'utilisation – CMS Croire & Penser

## Bienvenue !

Ce guide vous explique comment gérer le contenu de votre site **Croire & Penser** sans aucune connaissance technique. Tout se fait depuis votre navigateur web.

---

## 🔑 1. Se connecter au CMS

1. Ouvrez votre navigateur et allez sur : **votresite.com/cms**
2. Entrez vos identifiants :
   - **Email** : `admin@croireetpenser.ca`
   - **Mot de passe** : `admin123`
3. Cliquez **Se connecter**

> ⚠️ **Important** : Changez votre mot de passe après la première connexion.

---

## 📊 2. Tableau de bord

Après connexion, vous arrivez sur le **Tableau de bord** qui affiche :
- Nombre total de contenus publiés
- Nombre d'utilisateurs inscrits
- Nombre de prières reçues
- Nombre de questions posées

---

## 📝 3. Gérer les contenus (Articles, Vidéos, Podcasts)

### Créer un nouveau contenu

1. Dans le menu à gauche, cliquez sur **📝 Contenus**
2. Cliquez sur le bouton **+ Nouveau contenu**
3. Remplissez le formulaire :

| Champ | Description | Obligatoire |
|-------|-------------|:-----------:|
| **Titre** | Le titre de votre contenu | ✅ |
| **Type** | Article, Vidéo ou Podcast | ✅ |
| **Catégorie** | Thème (Dieu, Bible, Jésus-Christ, etc.) | ✅ |
| **Image de bannière** | URL d'une image (copiez le lien d'une image en ligne) | ❌ |
| **Lien vidéo** | URL YouTube (ex: `https://www.youtube.com/watch?v=xxxxx`) — apparaît si type = Vidéo | ❌ |
| **Fichier audio** | URL du fichier MP3 — apparaît si type = Podcast | ❌ |
| **Résumé** | Courte description affichée dans les cartes | ❌ |
| **Contenu** | Le texte complet de votre article | ✅ |
| **Tags** | Mots-clés séparés par des virgules | ❌ |
| **Contenu mis en avant** | Cochez pour le mettre en avant sur l'accueil | ❌ |
| **Publier immédiatement** | Cochez pour le rendre visible sur le site | ❌ |

4. Cliquez **Créer**

### Où apparaît le contenu ?

- **Page d'accueil** → Section "Contenu récent" (les 6 derniers publiés)
- **Page Contenus** (`/contents`) → Classé automatiquement dans Articles, Vidéos ou Podcasts
- En cliquant sur un contenu, les visiteurs peuvent :
  - 📖 **Lire** l'article complet
  - ▶️ **Regarder** la vidéo (player YouTube intégré)
  - 🎧 **Écouter** le podcast (lecteur audio intégré)
  - ❓ **Poser une question** directement sur le contenu

### Modifier un contenu

1. Allez dans **📝 Contenus**
2. Trouvez le contenu dans la liste
3. Cliquez **Modifier**
4. Faites vos changements
5. Cliquez **Mettre à jour**

### Supprimer un contenu

1. Allez dans **📝 Contenus**
2. Cliquez **Supprimer** à côté du contenu
3. Confirmez la suppression

---

## 🗣️ 4. Gérer les témoignages

Les visiteurs peuvent soumettre des témoignages depuis la page `/temoignages`. Ces témoignages arrivent **en attente de modération**.

### Approuver un témoignage

1. Dans le menu, cliquez sur **🗣️ Témoignages**
2. Vous voyez la liste avec le statut (En attente / Approuvé)
3. Cliquez **✅ Approuver** → le témoignage apparaît sur le site public
4. Cliquez **⏳ Retirer** → le témoignage disparaît du site (sans le supprimer)
5. Cliquez **🗑 Supprimer** → suppression définitive

### Filtrer les témoignages

Utilisez les boutons en haut :
- **Tous** : voir tous les témoignages
- **⏳ En attente** : ceux qui attendent votre approbation
- **✅ Approuvés** : ceux visibles sur le site

---

## ❓ 5. Gérer les Questions & Réponses

1. Dans le menu, cliquez sur **❓ Q&A**
2. Cliquez **+ Nouvelle question** pour ajouter une question avec sa réponse
3. Les questions soumises par les visiteurs apparaissent aussi ici

---

## 📄 6. Modifier les pages du site

1. Dans le menu, cliquez sur **📄 Pages**
2. Sélectionnez la page à modifier (Accueil, À propos, Contact, etc.)
3. Cliquez **Modifier**
4. La page s'ouvre dans un nouvel onglet en **mode édition**
5. Cliquez sur n'importe quel texte pour le modifier
6. Les modifications sont **sauvegardées automatiquement**
7. Fermez l'onglet quand vous avez terminé

---

## 🎬 7. Ajouter une vidéo YouTube

1. Allez sur YouTube et trouvez votre vidéo
2. Copiez l'URL de la barre d'adresse (ex: `https://www.youtube.com/watch?v=dQw4w9WgXcQ`)
3. Dans le CMS → Contenus → Nouveau contenu
4. Type : **Vidéo**
5. Collez l'URL dans le champ **Lien vidéo**
6. Ajoutez une image de bannière (optionnel — elle servira de miniature cliquable)
7. Publiez

> 💡 **Astuce** : Si vous ajoutez une bannière, les visiteurs verront l'image avec un bouton ▶ par-dessus. En cliquant, la vidéo se lance directement.

---

## 🎧 8. Ajouter un podcast / audio

1. Hébergez votre fichier audio (SoundCloud, Google Drive, etc.)
2. Copiez le lien direct du fichier MP3
3. Dans le CMS → Contenus → Nouveau contenu
4. Type : **Podcast**
5. Collez l'URL dans le champ audio
6. Publiez

---

## 👥 9. Gérer les utilisateurs

1. Dans le menu, cliquez sur **👥 Utilisateurs**
2. Vous pouvez voir la liste des inscrits
3. Cliquez **+ Nouvel utilisateur** pour en ajouter manuellement

## 🆘 FAQ

### Le contenu ne s'affiche pas sur le site ?
→ Vérifiez que vous avez coché **"Publier immédiatement"** lors de la création.

### La vidéo ne se lance pas ?
→ Vérifiez que l'URL est bien au format YouTube : `https://www.youtube.com/watch?v=XXXXX`

### Comment ajouter une image de bannière ?
→ Utilisez un service d'hébergement d'images (Imgur, Google Photos) et copiez le lien direct de l'image.

### Comment changer le mot de passe admin ?
→ Contactez votre développeur pour modifier les identifiants en base de données.

### Le témoignage approuvé n'apparaît pas ?
→ Rafraîchissez la page `/temoignages` (Ctrl+F5). Le témoignage doit avoir le statut "Approuvé".
