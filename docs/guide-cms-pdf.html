Guide de gestion du CMS

Croire & Penser — Manuel d'utilisation complet

🔑 1. Se connecter au CMS

1
Ouvrez votre navigateur
Allez sur votresite.com/cms
2
Entrez vos identifiants
Email : admin@croireetpenser.ca — Mot de passe : admin123
3
Cliquez "Se connecter"
Vous arrivez sur le tableau de bord.
⚠️ Changez votre mot de passe après la première connexion pour sécuriser votre compte.

📝 2. Créer un contenu (Article, Vidéo, Podcast)

1
Menu → Contenus → + Nouveau contenu
Le formulaire de création s'ouvre.
2
Remplissez les champs obligatoires
Titre, Type (article/vidéo/podcast), Catégorie, Contenu principal.
3
Ajoutez les médias (optionnel)
Vidéo : URL YouTube — Podcast : URL audio — Bannière : URL image
4
Cochez "Publier immédiatement"
Sans cette case, le contenu reste en brouillon invisible.
5
Cliquez "Créer"
Le contenu apparaît sur le site.

Tableau des champs

ChampDescriptionObligatoire

TypeArticle, Vidéo ou Podcast✅

📍 3. Où apparaît le contenu sur le site ?

PageCe qui s'affiche
AccueilLes 6 derniers contenus publiés
Contenus → ArticlesTous les articles
Contenus → VidéosVidéos avec player YouTube intégré
Contenus → PodcastsPodcasts avec lecteur audio
💡 Les visiteurs peuvent poser des questions directement sur chaque contenu.

🎬 4. Ajouter une vidéo YouTube

1
Copiez l'URL YouTube
Format : https://www.youtube.com/watch?v=XXXXX
2
CMS → Nouveau contenu → Type : Vidéo
Collez l'URL dans le champ "Lien vidéo".
3
Ajoutez une bannière (recommandé)
L'image sert de miniature. Au clic, la vidéo se lance.
💡 Sans bannière, le player YouTube s'affiche directement.

🎧 5. Ajouter un podcast / audio

1
Hébergez votre fichier audio
SoundCloud, Google Drive, ou tout hébergeur de fichiers.
2
CMS → Nouveau contenu → Type : Podcast
Collez l'URL du fichier MP3 dans le champ audio.

🗣️ 6. Gérer les témoignages

Les visiteurs soumettent des témoignages depuis /temoignages. Ils arrivent en attente de modération.

1
Menu → Témoignages
Liste de tous les témoignages avec statut.
2
Filtrez par statut
En attente / Approuvés.
3
Actions
✅ Approuver → visible — ⏳ Retirer → masqué — 🗑 Supprimer → définitif

📄 7. Modifier les textes des pages

1
Menu → Pages → Sélectionnez une page
Accueil, À propos, Contact, etc.
2
Cliquez "Modifier"
La page s'ouvre en mode édition (nouvel onglet).
3
Cliquez sur un texte → modifiez-le
Sauvegarde automatique à chaque modification.

❓ 8. Questions fréquentes

Le contenu ne s'affiche pas sur le site ?

→ Vérifiez que "Publier immédiatement" est coché.

La vidéo ne se lance pas ?

→ L'URL doit être au format : https://www.youtube.com/watch?v=XXXXX

Comment ajouter une image de bannière ?

→ Hébergez l'image en ligne (Imgur, Google Photos) et copiez le lien direct.

Le témoignage approuvé n'apparaît pas ?

→ Rafraîchissez la page avec Ctrl + F5.
